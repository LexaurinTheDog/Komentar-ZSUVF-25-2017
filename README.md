# Komentář k zákonu č. 25/2017 Sb., o sběru vybraných údajů pro účely monitorování a řízení veřejných financí

Otevřený komentář k zákonu o sběru vybraných údajů pro účely monitorování a řízení veřejných financí — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; dotčené osoby, měsíční a čtvrtletní údaje o příjmech a výdajích, garance a projekty PPP, způsob předkládání a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2017-00025_2025-07-01`.
